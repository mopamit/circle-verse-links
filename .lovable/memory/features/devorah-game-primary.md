# משחק דבורה - מבנה נוכחי

**שלב יחיד**: המעגל מסודר מראש (6 עיגולים, סדר נכון מקובע). אין שלב גרירת עיגולים.

**6 שלבי המעגל** (CORRECT_ORDER):
aziva → shibud → zeaka → shofet → nitzahon → sheket → (חוזר ל-aziva)

**7 פסוקים** (VERSES):
- v_pinned (ד,א) — נעוץ ב-aziva, לא ניתן לגרירה
- v_shibud (ד,ב-ג) → shibud
- v_zeaka (ד,ג) → zeaka
- v_shofet (ד,ד-ו) → shofet
- v_nitzahon (ד,כג) → nitzahon
- v_sheket (ה,לא) → sheket
- v_loop (ו,א) → aziva (פסוק חוזר — מציג המעגל סוגר)

**אינטראקציה**: גרירה (dnd-kit) או לחיצה על פסוק + לחיצה על עיגול.

**סיום**: כשכל הפסוקים שובצו → דיאלוג עם כפתור הורדת PNG (html-to-image) של המעגל המלא עם כותרת ולוגו עמית.
